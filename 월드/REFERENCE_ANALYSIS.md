# 월드 — 디자인 참고 자료와 포트폴리오 적용

후배들을 위해 제작한 디자인 포트폴리오의 월드 디자인 참고 자료 및 구현 분석 문서입니다.

분석 기준: 2026-10-21, [피치월드](https://pichiworld.co.kr/)의 실제 첫 화면 및 공개 HTML/CSS, `/main` 페이지의 공개 HTML.

## 원본의 구성

첫 화면은 브랜드와 프랜차이즈를 선택하는 전체 화면 게이트입니다. 위쪽은 우주 배경의 퍼플, 아래쪽은 네온그린입니다. 하단 패널의 상단을 `clip-path: polygon(...)`으로 기울여 두 영역을 연결합니다. 가운데 상단에는 로고, 좌측에는 환영 문구, 우측에는 서울 시간과 온라인 상태가 있습니다.

타이포그래피는 두껍고 좁은 영문 대문자를 크게 사용하며, 눈썹 제목은 작은 점·가로선·한글 보조 문구로 구성합니다. 브랜드의 캐릭터와 음식 사진을 타이포그래피 오른쪽에 크게 배치하고, 노랑·분홍·보라의 별과 방사형 장식을 겹칩니다.

원본은 패널 hover/focus-visible 시 flex-grow를 늘려 선택 영역을 확장합니다. 설명과 흰색 pill CTA, 통계가 나타나며 캐릭터가 바뀌거나 음식이 이동·회전·확대됩니다. 이동에는 약 0.65초와 cubic-bezier(0.22,1,0.36,1)를 사용합니다.

## 색상과 반응형

| 요소 | 원본 CSS에서 확인한 값 | 적용 |
| --- | --- | --- |
| 퍼플 | #6a00ef | 포인트·연락처·장식 |
| 그린 | #12dd24 | 프로젝트 게이트·필터 |
| 노랑 | #fff323 | 별·마키·강조 |
| 분홍 | #e83cff | 별·프로젝트 그래픽 |
| 어두운 바탕 | #050505 및 검정 | 포트폴리오에는 #17121f |

원본 분기점은 1024px, 768px, 375px입니다. 1024px에서는 제목·캐릭터·음식·패널 경계를 축소하고 위치를 바꿉니다. 768px에서는 상태 표시를 숨기고 hover 전용 설명·통계를 제거하며, 장식과 콘텐츠를 세로 화면에 맞춥니다. 375px에서는 상단 환영 문구와 일부 보조 문구도 숨깁니다. `100svh`, clamp, reduced-motion 분기도 확인했습니다.

## 포트폴리오 적용

게이트는 ABOUT ME와 PROJECTS로 교체했습니다. 색과 대각선 경계, 상단 구조, 제목 비중, hover 확장과 장식 문법을 반영했습니다. 캐릭터는 코드가 비치는 우주인 SVG, 음식은 노트북 SVG로 직접 제작해 대체했습니다. 실제 정보 탐색을 위해 하단에 소개·툴박스·프로젝트·연락처를 연결했습니다.

모바일은 소개를 읽을 수 있도록 짧은 설명과 CTA를 상시 표시합니다. 데스크톱은 원본처럼 hover 및 키보드 focus 시 상세 내용을 표시합니다. 원본의 상업용 HGGOTHIC/Adobe 폰트 대신 Barlow Condensed와 Pretendard를 사용했습니다. 따라서 원본과 픽셀 단위로 완전히 동일한 복제는 아니며, 포트폴리오에 맞게 콘텐츠와 일러스트를 변경한 구현입니다.
