# 후배들을 위한 디자인 포트폴리오

후배들을 위해 제작한 디자인 포트폴리오입니다. 다양한 디자인을 참고하고, 자신의 이야기를 채워 나만의 포트폴리오를 만들 수 있도록 준비했습니다.

인스타그램 프로필에서 영감을 받은 디자인 선택 홈과, 폴더별로 독립 실행하는 HTML 포트폴리오 템플릿을 담았습니다.

압축을 푼 뒤 **최상위 `index.html`을 더블클릭**하세요. 각 폴더의 `index.html`을 직접 열어도 됩니다. 페이지를 보는 데 설치·빌드·서버·로그인이 필요하지 않습니다.

## 홈 사용하기

- **원형 하이라이트 / 게시물**: 해당 템플릿을 바로 엽니다.
- **검색**: 이름·설명·스타일 태그로 찾습니다.
- **책갈피**: 좋아하는 디자인을 저장합니다. `저장됨`에서 모아 볼 수 있습니다.
- **사용 방법**: 홈에서 안내 창을 엽니다. Escape로 닫을 수 있습니다.
- **휴대전화 화면**: 하단 메뉴와 3열 게시물 그리드로 표시됩니다.

저장 목록은 현재 브라우저의 localStorage를 사용합니다. 브라우저·도메인·파일 경로가 바뀌면 목록이 달라질 수 있으며, 저장 공간이 제한되면 현재 탭에서만 유지됩니다. 로그인이나 외부 서버로의 전송은 없습니다.

## 새 템플릿 추가하기

1. 이 README와 같은 위치에 새 디자인 폴더를 넣습니다. 폴더 안에는 `index.html`과 필요한 CSS·JS·이미지가 있어야 합니다.
2. **`목록-업데이트.command`를 더블클릭**합니다.
3. 홈을 새로고침하면 새 폴더가 연결되고, `HTML-디자인-템플릿.zip`도 갱신됩니다.

목록 갱신 도구는 Python 3을 사용합니다. 이미 만든 HTML을 실행할 때는 Python이 필요하지 않습니다. 터미널에서는 아래 명령을 사용할 수 있습니다.

```sh
python3 scripts/update-templates.py --package
```

제목·한 줄 소개·스타일 태그·표시 순서를 바꾸려면 `templates.config.json`을 수정하세요. 설정에 없는 새 폴더도 자동으로 찾아 등록합니다. `preview/desktop.png`, `.jpg`, `.webp`가 있으면 미리보기로 사용합니다. 아직 HTML이나 필수 파일이 완성되지 않은 항목은 `제작 중`으로 표시해 잘못된 실행 링크를 만들지 않습니다.

## 수정·공유·GitHub

각 디자인의 콘텐츠 수정법은 해당 폴더의 README를 확인하세요. 하나만 공유할 때도 이미지와 폰트가 포함된 폴더 전체를 전달해야 합니다. 외부 프로젝트 링크를 열 때는 인터넷이 필요합니다.

GitHub에는 위 파일과 디자인 폴더들을 같은 구조로 올리면 됩니다. GitHub 파일 화면 자체에서는 HTML이 실행되지 않으므로, 내려받아 열거나 정적 호스팅을 사용하세요. 별도 프레임워크나 서버 앱은 필요하지 않습니다.

폰트·지구 텍스처·레퍼런스 배경 등의 출처·라이선스는 각 디자인 폴더에서 확인하고 함께 유지하세요. 템플릿의 예시 내용은 본인의 실제 정보로 바꿔 사용하세요.

## Pages 배포

이 저장소는 기본 브랜치의 루트 디렉터리를 GitHub Pages로 게시합니다. 변경한 파일을 커밋·푸시하면 GitHub가 사이트를 갱신합니다. 새 디자인을 추가했으면 먼저 목록 갱신 도구를 실행하고, 해당 폴더와 변경된 홈 파일을 함께 푸시하세요.
