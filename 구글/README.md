# Rem — Antigravity-inspired portfolio

Google Antigravity의 화면 구성과 반응형 동작을 참고해 만든 **HTML / CSS / Vanilla JavaScript** 포트폴리오입니다. 프레임워크, 설치, 빌드, API 키가 필요하지 않습니다. `index.html`을 더블클릭하면 바로 열립니다. 폴더 전체를 함께 옮겨주세요.

## 포함된 화면과 기능

- 흰 배경, 큰 중앙 타이포그래피, 검은 버튼, 마우스에 반응하는 Canvas 입자
- 검은 모션 쇼케이스와 직접 제작한 점 형태의 3D 리본
- 교차 배치 프로젝트, 프로젝트 상세 모달, 인터랙티브 공전 일러스트
- 한국어 / 영어 전환과 브라우저 내 언어 설정 저장
- 모바일 메뉴, 키보드 탭 이동, 이메일 복사, 동작 정지
- 1100 / 900 / 767 / 390px 반응형 전환, 320px 이상의 화면 대응
- 시스템 동작 줄이기, 화면 밖 Canvas 정지, 숨겨진 탭 애니메이션 정지

## 수정할 곳

| `index.html` | 브랜드, 소개, 프로젝트, 연락처와 기본 한국어 문구. `data-en` 속성은 영어 문구 |

## 로컬 미리보기 (선택)

```sh
python3 -m http.server 4190 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4190`을 엽니다. 종료는 `Ctrl+C`입니다. `file://`로 직접 열어도 기본 기능이 동작하며, 프로젝트 외부 링크에는 인터넷이 필요합니다.

## 검증 기록

2026-10-21 Chrome의 실제 CSS 뷰포트 320 / 390 / 768 / 1440px에서 문서 가로 넘침 없음, 모바일 메뉴 접힘, 프로젝트 한 열/두 열 전환을 확인했습니다. 한국어/영어 전환, 프로젝트 모달과 링크 생성, 320px 모달 크기, 모바일 메뉴 열기·닫기, 기술 탭과 키보드 방향키 이동, 이메일 복사 알림을 확인했습니다. 브라우저 콘솔 오류·경고 0건, 깨진 이미지 0건이며 JS 문법과 로컬 파일·앵커 경로 검사를 통과했습니다. 실제 휴대폰에서의 검증은 별도입니다.

브라우저 자동화의 URL 보안 정책이 `file://` 탐색을 허용하지 않아 자동 직접 실행 검사는 수행하지 못했습니다. 외부 모듈·fetch·CDN 없이 상대 경로의 CSS·일반 JS·로컬 폰트를 사용하는 구조이며, 직접 실행 시에는 사용자가 `index.html`을 더블클릭하면 됩니다.

## 원본 분석과 출처

2026-10-21 Chrome에서 https://antigravity.google/ 의 데스크톱과 440px 모바일 화면을 확인했습니다. 데스크톱의 큰 중앙 히어로, 입자 배경, 어두운 영상 영역, 원형 아이콘 띠, 프로젝트 교차 배치, 넓은 여백을 포트폴리오에 맞게 구성했습니다. 모바일의 메뉴 접힘, 제목 축소, 한 열 콘텐츠 흐름을 적용했습니다. 원본 CSS에는 1024px, 768px, 767px 관련 미디어 쿼리가 있었습니다. 이 템플릿의 전환점은 자체 콘텐츠에 맞게 조정했습니다.

Google 로고, 사이트 이미지, 동영상, 원본 소스 코드는 포함하지 않았습니다. 일러스트·리본·입자는 HTML/CSS/Canvas로 새로 제작했습니다. 앱 목업과 터미널 출력은 소개용 일러스트이며, 실제 제품 화면이나 실행 결과가 아닙니다. 공전 속도 슬라이더는 애니메이션 데모이며 물리 시뮬레이터가 아닙니다.
