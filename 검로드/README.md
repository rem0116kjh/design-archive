# 비행기 — 네온 디자인 포트폴리오

후배들을 위해 제작한 디자인 포트폴리오입니다. 다양한 디자인과 코드를 참고하고, 자신의 이야기로 바꿔 사용할 수 있도록 준비했습니다.

[Gumroad](https://gumroad.com/)의 2026-10-21 공개 화면에서 영감을 받은 개발자 포트폴리오 템플릿입니다. 큰 타이포그래피와 명확한 구획에서 출발해, 네온 라임 주색과 절제된 민트 보조색, 차콜 배경과 종이비행기 그래픽, 비대칭 메인 구성을 사용한 독립적인 디자인으로 바꿨습니다. Gumroad와 제휴한 사이트가 아닙니다.

`index.html`을 더블클릭하면 열립니다. 설치·빌드·서버 없이 실행되며, 폰트와 그래픽을 폴더 안에 포함했습니다. 외부 프로젝트 링크만 인터넷이 필요합니다. 공유할 때는 이 폴더 전체를 전달하세요.

## 구성과 기능

- 소개 → 프로젝트 4개 → 자기소개·기술 → 만드는 과정 → 연락처.
- 프로젝트 분야 필터와 키보드·Escape로 닫을 수 있는 상세 창.
- 모바일 메뉴, 라이트·다크 전환, 이메일 복사.
- 320px부터 데스크톱까지 반응형. 시스템의 동작 줄이기 설정을 반영합니다.
- JavaScript가 없어도 소개·프로젝트·외부 링크·연락처와 기술 아코디언을 사용할 수 있습니다.

테마는 브라우저의 `rem-log.neon.theme.v1` 키에만 저장합니다. 저장이 제한되어도 현재 탭에서 전환할 수 있습니다. 이메일 복사는 브라우저의 클립보드 지원 상태에 따라 복사 또는 주소 선택으로 작동합니다.

## 내 내용으로 바꾸기

1. `index.html`에서 이름, 소개, 프로젝트 카드, 기술, 연락처와 외부 링크를 바꿉니다.
2. `script.js`의 `projects`에서 상세 창의 내용과 링크를 바꿉니다. 이메일은 HTML의 주소·메일 링크와 JS의 `email`을 함께 수정합니다.
3. 프로젝트의 `data-category`와 필터의 `data-filter`를 맞춥니다. 전체 개수는 HTML에서 함께 바꿉니다.
4. `neon.css`의 `:root` 색상 변수와 `assets/paper-plane.svg`, `assets/favicon.svg`의 종이비행기를 바꾸면 브랜딩을 수정할 수 있습니다.

프로젝트 설명·참여 범위·연락처는 이 아카이브의 `렘/` 템플릿에서 가져왔습니다. 수상·사용자 수·성과 수치는 추가하지 않았습니다. 프로젝트 그림은 이 템플릿용으로 새로 만든 설명용 그래픽이며 실제 앱 화면이 아닙니다.

## 파일과 출처

- `index.html` — 정적 콘텐츠, 프로젝트 그래픽, 페이지 구성.
- `style.css` — 반응형 레이아웃과 종이비행기 애니메이션.
- `neon.css` — 색상 역할별 변수, 다크·라이트 팔레트와 절제된 그림자. 기본 화면은 다크 모드입니다.
- `script.js` — 필터, 상세 창, 테마, 메뉴, 이메일 복사.
- `assets/` — 새로 만든 종이비행기·파비콘, 로컬 폰트와 라이선스.
- `preview/` — 아카이브용 실제 브라우저 캡처.
- 디자인 참조: [Gumroad](https://gumroad.com/). 원본 로고·코인·일러스트·전용 폰트는 복제하지 않았습니다.
- Manrope와 Pretendard: SIL Open Font License. `assets/licenses/`에 라이선스를 포함했습니다.

이 디자인은 최상위 디자인 포트폴리오의 공개 배포와 공유용 ZIP에 포함됩니다. 본인의 내용으로 수정한 버전은 폴더 전체를 복사해 공유하거나 정적 호스팅에 올릴 수 있습니다.

색상 검토와 변경 이유는 `DESIGN-REVIEW.md`를 참고하세요.
