# 검증 기록 — 2026-10-21

후배들을 위해 제작한 디자인 포트폴리오의 애플 디자인 기능·성능 검증 기록입니다.

환경: macOS의 Codex 내장 Chromium 브라우저, 로컬 HTTP 미리보기. Playwright 기반 UI 조작과 DOM 상태 읽기로 확인했습니다. 모바일·태블릿 크기는 브라우저 뷰포트이며 물리 기기 검증이 아닙니다.

## 공통 데스크톱 / 디자인 시스템 기능

다음 항목은 동일한 창 관리·테마·앱 코드에 대해 디자인 시스템 버전에서 브라우저 UI로 확인했습니다.

- 포인터 드래그로 창 좌표 변경.
- 키보드 크기 조절로 창 너비·높이 변경.
- 창 최소화·복원·최대화·일반 크기 복원.
- 새 메모 작성과 새로고침 후 제목 유지. `<script>` 형태의 메모를 텍스트로 표시.
- 가상 폴더 생성·검색·목록 보기 전환.
- 터미널 Tab 자동완성과 위쪽 화살표 명령 기록.
- Ctrl + K 검색, 위·아래 탐색, Enter로 앱 실행.
- 테마 실시간 변경, CSS / JSON / Tailwind 파일 다운로드.
- 내려받은 CSS의 변수 15개 확인, JSON 스키마 파싱, Tailwind 설정을 Node에서 읽어 색상 일치 확인.
- 잘못된 테마 JSON 거부, 내보낸 정상 JSON 재가져오기.
- Button의 disabled / loading 상태, Tabs 전환, Carousel 다음 슬라이드, Dialog 열기·닫기.
- 소스 HTML 다운로드 후 구문 검사, 테스트용 개인 메모가 포함되지 않음 확인.

## 확인하지 않은 범위

- Safari / Firefox, 물리 모바일 기기, 스크린리더를 사용한 전체 접근성 감사.
- Lighthouse 점수, Core Web Vitals, 물리 기기의 프레임률. 브라우저에서 수행한 제한된 정량 비교는 아래 성능 최적화 항목에 별도 기록했습니다.
- 공개 배포·실제 소셜 계정·실제 이메일 전송·이력서 PDF 서버 응답.
- 브라우저 도구는 `file:` URL을 허용하지 않아 파일 직접 열기는 도구로 실행하지 않았습니다. HTTP 미리보기 동작과 내보낸 파일의 정적 구문·구성은 확인했습니다.

가상 파일은 실제 OS 파일이 아니며, 터미널은 고정된 명령어 시뮬레이터입니다. 브라우저 저장이 제한되면 알림으로 알리고 HTML / JSON 내보내기로 보존할 수 있습니다.

## 한국어·실시간 물결 배경 후속 검증 — 2026-10-21

- 문서 언어 `ko`, 한국어 메뉴·기본 소개·편집기·프로젝트·컴포넌트·설정·날짜 표시 확인.
- 기존 SVG 배경의 4개 색상 층과 2개 윤곽선에 애니메이션 적용. 서로 다른 시점의 CSS 변환 행렬이 변경되는 것을 확인.
- 움직이는 배경 끄기: `animation-play-state: paused` 확인. 다시 켜기: `running` 확인.
- 화면 동작 끄기: 배경의 `animation-name: none` 확인. OS `prefers-reduced-motion`에도 애니메이션을 제거하는 CSS 포함.
- 일반 페이지 보기: 보이지 않는 배경의 애니메이션이 `paused`인 것을 확인.
- 한국어 변경 후 320·390·768·1024·1440px에서 데스크톱·일반 페이지 모두 페이지 가로 넘침 없음. 모바일 앱 런처 아이콘이 Dock과 겹치지 않음 확인.
- 한국어 편집기 프로젝트 필드, 컴포넌트 선택 및 탭 미리보기 정상 표시. 브라우저 error / warn 로그 없음.
- 저장소 모의 검증: 기존 저장 키 유지, 기본 예시 문구만 한국어로 변환, 사용자 이름·상세 소개·연락처·프로젝트 ID·URL·개인 메모·수정 시각 보존 확인. 기본 테마 이름 변환 확인.
- 최신 HTML 스크립트 구문 검사 통과.

## 자연스러운 물결·포인터 반응 개선 — 2026-10-21

- 기존 층 전체의 회전·왕복 CSS 애니메이션을 SVG 곡선 변형으로 교체. 4개 물결 층과 2개 윤곽선에 서로 다른 주기의 애니메이션이 생성되는 것을 확인.
- 브라우저에서 서로 다른 시점의 `computedStyle.d`가 변하는 것 확인. 모든 곡선의 반복 첫 값과 마지막 값이 정확히 일치하는지 단위 검증.
- 실제 포인터를 왼쪽·오른쪽으로 이동해 배경의 `translate3d`가 음수·양수로 부드럽게 바뀌는 것 확인. 배경 이동 범위는 가로 10px·세로 7px.
- 관성 보간 수식에 30·60·120Hz 입력 간격을 주어 같은 시간이 지난 후 위치가 일치하고 목표를 넘어가지 않는 것 확인. 실제 기기의 FPS를 측정한 결과는 아님.
- 움직이는 배경 끄기: SVG 상태 `paused`, 포인터 `disabled`, 이동량 0. 시간 간격을 두고 읽은 곡선 모양이 동일한 것 확인.
- 화면 동작 끄기: SVG·포인터 정지와 배경 표면의 `transform: none` 확인. 다시 켜면 재생 복원. 일반 페이지 보기에서도 SVG가 멈추는 것 확인. OS 동작 줄이기 변경 감지 및 인쇄 전후 일시정지 처리 포함.
- 320·390px에서 물결 6개 재생, 모바일용 16개 곡선 키프레임, 포인터 반응 비활성, 표면 이동 없음 확인. 곡선 키프레임 수는 표시 프레임률과 다름. 진폭은 데스크톱의 절반, 주기는 1.2배로 구성.
- 390px 프로젝트 앱 실행·홈 복귀 확인. 320·390·768·1440px에서 페이지 가로 넘침 없음.
- 브라우저 error / warn 로그 없음. HTML 내 실행 스크립트 구문 검사 통과.

이번 모바일 확인은 Chromium 뷰포트 기준이며, 물리 기기·Safari·배터리 소모·실제 프레임률 측정은 수행하지 않았습니다.

## 모바일 성능 최적화 — 2026-10-21

- 변경 전 HTML을 `performance/baseline.html`에 보관하고, 같은 390×844 / DPR 1 브라우저 화면에서 워밍업 후 기준·최적화 버전을 3회씩 교차 측정했습니다. 원시 결과와 재현 방법은 `performance/`에 있습니다.
- 활성 창 20회 누르기: DOM 변경이 3회 모두 340건 → 0건. 이미 활성 상태인 창의 순서·Dock 중복 갱신을 제거했습니다.
- 모바일 앱 사용 중 SVG 물결 6개 정지 확인. 시간 간격을 두고 읽은 곡선 모양이 동일했고, 마지막 앱 최소화 후 기존 곡선에서 이어지는 것 확인. 홈·닫기 후에도 재생을 복원합니다.
- 모바일 비활성 앱의 `visibility:hidden`과 `inert` 확인. 앱 DOM을 유지하여 메모·스크롤·편집 중 값을 보존합니다. 실제 UI에서 저장 전 한 줄 소개를 입력하고 앱 전환·홈 복귀 후 값이 남는 것을 확인했으며 검증용 입력은 원래 값으로 되돌렸습니다.
- 앱 전환 프레임 간격 p95: 기준 34.1 / 34.1 / 34.3ms, 최적화 34.1 / 34.1 / 34.1ms. 50ms 초과 간격은 기준 441개·최적화 440개 표본 모두 0건. 앱 전환 중 Long Task도 양쪽 모두 0건.
- 열기·닫기 이벤트 처리 p95는 기준 2.8 / 2.4 / 6.9ms, 최적화 3.0 / 11.3 / 2.5ms로 변동했습니다. **실행 속도나 프레임률 향상을 주장하지 않습니다.** 확인한 개선은 중복 DOM 갱신과 앱 사용 중 배경 애니메이션 작업 제거입니다.
- 320·390·768·1440px 각각 13개 앱을 열고 닫는 총 52회 검증 통과. 가로 넘침, 활성 앱 접근, 모바일 비활성 앱 숨김, 메모 보존, 종료 후 DOM 제거, 일반 페이지 배경 정지 확인.
- 320·390px에서 홈 복귀·앱 복원·움직이는 배경 끄기·화면 동작 끄기·다시 켜기 확인. 앱을 닫거나 홈으로 돌아가도 사용자 정지 설정을 무시하지 않습니다.
- 원본 콘텐츠 JSON·저장소 코드·메모 저장 코드가 변경 전과 동일한 것을 정적 비교로 확인. 원본과 최신 내보낸 HTML의 스크립트 구문 검사 통과. 내보낸 HTML에 최적화 코드가 포함되고 검증 전용 코드는 포함되지 않음 확인.
- 실제 미리보기와 성능 검증 페이지의 브라우저 error / warn 로그 없음.

성능 수치는 macOS의 내장 Chromium 브라우저에서 얻은 값입니다. 이 세션의 프레임 콜백 간격은 약 33.3ms였으며, 물리 모바일 기기·Safari·GPU/CPU 사용률·배터리 소모·실제 터치 지연 검증은 수행하지 않았습니다.
