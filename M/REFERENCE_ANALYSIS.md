# MAKERVIL → M 포트폴리오 적용 분석

참조: [MAKERVIL 영문 홈](https://www.makervil.com/en), 2026-10-21 확인.

1280×720 데스크톱과 390×844 모바일 화면을 직접 열어 첫 화면, 스크롤 구역, 모바일 메뉴를 관찰했습니다. 아래 원본 설명은 관찰 결과이며, M의 수치와 중단점은 별도로 정한 구현 값입니다.

| 관찰한 원본의 UI / UX | M의 포트폴리오 적용 |
| --- | --- |
| 상단 왼쪽과 하단 오른쪽으로 분산된 큰 제목, 중앙 금속 조형물 | 같은 시선 흐름에 개인 작업 선언과 직접 제작한 금속 M SVG 배치 |
| 흑백 테마와 가는 기준선 | 흑백 의미 색상 변수, 스크롤 위치를 보여주는 세로 기준선 |
| 고정 헤더와 중앙 테마 조작 | 소개·프로젝트·작업 방식·기록·연락처 앵커와 테마 스위치 |
| 큰 소개 문장 다음에 오른쪽에 놓인 짧은 설명 | 개인의 관점과 소개 문장, 작업 방식으로 이어지는 링크 |
| 크기가 다른 이미지와 여백을 활용한 브랜드 배치 | 두 열의 비대칭 프로젝트 이미지, 항상 보이는 열기 버튼과 상세 사례 |
| 서비스의 세 가지 구분 | Understand / Connect / Refine 작업 과정 |
| 뉴스 목록과 큰 연락 유도 문구 | 펼쳐 읽는 작업 기록과 이메일 연락 영역 |
| 모바일에서 제목·조형물·설명이 세로로 재배치됨 | 800px·540px 단계로 메뉴와 배치를 전환, 최소 화면 높이 확보 |
| 모바일에서 큰 메뉴와 연락처를 한 화면에 제공 | native dialog로 전체 화면 메뉴 구성, 포커스 제한·복원·Escape 닫기 |

## 구현 선택

- 원본의 3D 장면은 로컬 SVG로 재해석했습니다. 실제 3D 렌더링이나 원본 모델의 복제가 아닙니다. 작은 화면에서는 포인터 동작을 사용하지 않습니다.
- 소개나 기록을 화면 밖에서 불러오지 않습니다. 기본 콘텐츠를 정적 HTML로 유지하고 효과를 보조적으로 적용합니다.
- 포트폴리오 탐색에 필요한 프로젝트 필터와 사례 상세 창을 추가했습니다. 호버가 없어도 같은 정보와 동작에 접근할 수 있습니다.
- 사이트의 실제 회사 수치·제품 설명·사진은 개인의 성과로 전용하지 않았습니다. 프로젝트는 예시임을 상세 화면과 README에서 명시합니다.
- 과도한 자동 재생·긴 로딩을 넣지 않았습니다. 동작 줄이기 설정에서는 진입 효과와 포인터 기울기를 해제합니다.
