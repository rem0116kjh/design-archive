# 참고 사이트 최종 비교

확인일: 2026-10-21

참고: https://wacusglobal.com/en

## 판정

회전하는 지구, 지구 앞뒤를 도는 프로젝트, 어두운 우주 배경, 큰 타이포그래피라는 핵심 방향을 반영했습니다. 후배들이 자신의 콘텐츠로 교체하는 포트폴리오 템플릿으로 재해석한 결과입니다. 전체 화면 구성과 모든 스크롤 장면이 원본과 동일한 것은 아닙니다.

## 직접 비교한 부분

| 항목 | 참고 사이트에서 확인한 구성 | ORBIT에서 확인한 결과 |
| --- | --- | --- |
| 지구 | 화면의 중심이 되는 회전 지구와 빛·구름 | WebGL 지표·구름·조명·대기 효과와 실제 자전 정상 |
| 프로젝트 궤도 | 지구를 감싸는 띠와 앞뒤 원근 | 독립 프로젝트 카드 5개가 지구 앞뒤로 공전. 최종 검토에서 궤도 방향에 따른 3D 기울기 보강 |
| 스크롤 | 같은 3D 장면을 길게 유지하며 여러 단계로 변화 | 긴 고정 구간에서 궤도 탐색 → 지구 확대 → 카드 펼침 → 다음 이야기의 4단계 전환. 역방향 스크롤도 같은 경로로 복원 |
| 타이포그래피 | 큰 산세리프와 넓은 여백, 강한 포인트 색 | 큰 산세리프와 여백을 유지하고 화이트·딥 네이비로 재해석 |
| 프로젝트 소개 | 여러 작업 화면을 활용하는 시각적 소개 | 교체 가능한 예시 이미지, 분야 필터, 상세 팝업으로 구성 |
| 하단 내용 | 회사 서비스·FAQ·문의·브랜드 중심 | 자기소개·프로젝트·경험·연락처 예시로 구성 |
| 재사용 | 회사의 실제 콘텐츠 | 개인 식별 정보 없는 예시 콘텐츠와 설정·수정 가이드 포함 |

카드는 원근이 적용된 개별 HTML 평면입니다. 원본의 곡면 리본 메시, 지구의 야간 도시 불빛, 하단 대형 브랜드 글자 전환은 포함하지 않았습니다. 장면의 세부 동선과 문구도 ORBIT에 맞게 새로 구성했습니다.

## 이번에 보강한 부분

`assets/scroll-story.js`에서 스크롤 진행도에 따라 지구의 위치·확대율·회전과 카드의 펼침을 함께 제어합니다. CSS sticky로 한 화면을 유지하면서 지구가 약 2배 커지고, 프로젝트 5개가 궤도를 벗어나 화면 전체로 펼쳐진 뒤 위로 이동합니다. 문구도 장면에 맞춰 교차하며, 마지막 장면에서 자기소개로 연결됩니다.

하단 장면 버튼, 역방향 스크롤, 화면 크기 변경에 따른 진행도 유지, 모션을 끌 때 일반 첫 화면으로 복귀하는 동작을 포함합니다. 모바일은 더 짧은 구간과 별도 카드 위치를 사용합니다. 시스템 모션 줄이기에서는 긴 고정 구간을 사용하지 않습니다. 기존 드래그·키보드·필터·팝업과 개인 정보 없는 예시 콘텐츠는 유지했습니다.

## 검증 범위와 증거

- 참고 사이트: 데스크톱 1440×960에서 직접 접속해 초기 지구·띠 모양 궤도와 스크롤 중간의 3D 장면을 관찰했습니다. 하단 콘텐츠 구성은 페이지 본문과 DOM을 확인했습니다.
- 참고 사이트 모바일: 390×844에서 접속·재접속했으나, 이번 브라우저 환경에서는 로딩 오버레이가 제한된 대기 시간 안에 사라지지 않았습니다. 모바일 원본의 최종 장면 전체를 검증했다고 주장하지 않습니다.
- ORBIT: 320·375·390·768·1024·1440px에서 모든 섹션 가로 넘침 없음, 이미지 정상, 카드 1·2·3열 배치 확인.
- 자전·공전: 시간 경과에 따른 지구 각도와 궤도 위상의 실제 변화 확인.
- 원근: 카드의 실제 계산 결과가 matrix3d이며 궤도에 따라 각도가 바뀌는 것 확인.
- 스크롤: 320×568·375×812·390×844·768×960·1024×768·1440×960에서 4개 장면의 고정 위치·확대·카드 이동·역방향 복원 확인.
- 장면 버튼·화면 크기 변경·모션 전환 시 읽던 위치 유지·프로젝트 직접 링크 확인.
- 마우스 드래그, 모바일 가로 스와이프·세로 스크롤, 키보드 회전, 모션 정지·설정 저장, 필터·상세 보기 정상.
- 화면 밖 자동 정지, 모션 줄이기, 파일 직접 열기에서 WebGL, CSS 대체 경로, JavaScript 없는 기본 탐색 정상.
- 실물 모바일 기기의 성능·프레임률은 이번 검증에 포함하지 않았습니다.
