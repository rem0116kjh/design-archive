# 검증 기록

후배들을 위해 제작한 디자인 포트폴리오의 폭발 디자인 브라우저 검증 기록입니다.

검증일: 2026-10-21 (Asia/Seoul)

검증 환경은 macOS의 Codex 인앱 브라우저입니다. 실제 휴대전화 설치·물리 기기 성능 검증과 구분합니다.

반응형 실측은 `preview/responsive.json`에 기록했습니다. `viewport`는 CSS viewport, `pageWidth`는 세로 스크롤바를 제외한 너비입니다. `scrollWidth === pageWidth`이며 `widestLine <= heroWidth`임을 확인했습니다.

## 개인 포트폴리오 연결 후 검증

- 현재 `portfolio-react/src/translations.js`의 소개·기술 6개 분야·프로젝트 5개·대회·자격 12개·활동 17개를 대조했습니다.
- 5개 프로젝트 상세 창이 각각 올바른 이름·기술·소개와 공개 링크 7개를 표시함을 브라우저에서 확인했습니다.
- `대회·자격 12`와 `활동·경험 17` 펼치기에서 원본의 전체 기록이 표시됩니다.
- GitHub·Velog·메일·원본 포트폴리오 연결 주소가 원본과 일치합니다.
- GHAS는 실제 앱 화면, 다른 프로젝트는 설명용 일러스트로 표시했습니다.
- 기존 React 포트폴리오의 소스는 수정하지 않았습니다.

콘텐츠와 연결 상태를 검증한 결과이며, 외부 앱·대회·메일 계정의 현재 상태를 독립적으로 인증한 결과는 아닙니다.

## 3D 전시 추가 검증

- 실제 320 / 375 / 390 / 768 / 1024 / 1440px viewport에서 가로 넘침이 없고 Canvas 크기가 전시 영역과 일치합니다. preview/3d-responsive.json에 실측을 저장했습니다.
- 프로그램 탭 5개의 선택 상태, 해당 소개 패널, 프로젝트 상세 제목·링크가 일치합니다.
- 실제 포인터 드래그로 3D 시점이 바뀌며, 방향키 회전·초기화·탭 방향키 선택이 동작합니다.
- JavaScript 없는 전용 문서에서 5개 프로그램 소개가 모두 보이며, 빈 전시 영역은 숨겨집니다.
- 동작 줄이기 신호를 모사한 전용 문서에서 인트로 생략과 3D 프로그램 선택이 정상입니다.
- 위 검사 중 브라우저 콘솔 오류·경고가 없습니다. 물리 휴대전화의 터치·GPU 성능을 검증한 결과는 아닙니다.
