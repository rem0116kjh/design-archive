# LUKA Portfolio — HTML 포트폴리오 템플릿

`index.html`을 브라우저로 열면 바로 실행됩니다. 설치, 빌드, 프레임워크, 서버가 필요하지 않습니다. 스타일·스크립트·아이콘·배경은 HTML 안에 포함되어 있습니다.

## 내 포트폴리오로 바꾸기

1. 오른쪽 아래 **편집하기**를 엽니다. 모바일에서는 오른쪽 위 슬라이더 버튼입니다.
2. **소개**에서 이름·직무·소개·프로필 사진을 수정합니다.
3. **프로젝트**에서 프로젝트, 실제 역할, 문제·접근·결과, 기술 태그, 링크를 입력합니다. 프로젝트 추가·삭제와 표지 선택을 지원합니다.
4. **기술 / 경험 / 연락처**에서 기술·경험·이메일·소셜·이력서를 수정합니다. 이메일과 링크를 비우면 해당 링크는 표시하지 않습니다.
5. **변경 사항 저장**는 현재 브라우저의 초안을 저장합니다.
6. **HTML 내보내기**은 수정한 콘텐츠·테마·설정이 포함된 `my-portfolio.html`을 다운로드합니다. 공유하거나 호스팅할 때 이 파일을 사용합니다. 저장 버튼만 누르면 다른 사람에게 변경 사항이 전달되지 않습니다.

JSON 내보내기·가져오기도 지원합니다. 프로필 이미지는 PNG / JPEG / WebP, 1.4 MB 이하입니다. 이미지가 없으면 이름의 이니셜을 표시합니다. 외부 프로젝트·이력서 링크를 상대 경로로 입력했다면, 배포할 때 그 파일도 함께 복사해야 합니다.

## 코드에서 직접 수정

`index.html`의 `<script id="portfolio-config" type="application/json">` 블록이 콘텐츠 원본입니다. `profile`, `projects`, `skills`, `experience`를 수정하세요. JSON 문법을 유지해야 합니다. 기존 브라우저 초안이 우선하므로 원본을 새 템플릿으로 적용할 때 `storageId`도 새로운 값으로 변경하세요.

기본 이름·자기소개·기술·경험은 템플릿용 예시입니다. 실제 개인 경력·수상·연락처로 확인한 내용이 아닙니다. 사례 프로젝트의 예시 표시는 편집기에서 변경할 수 있습니다. 측정하지 않은 성능 점수나 성과 수치를 넣지 않았습니다.

## 방문자 화면

- **데스크톱**: 포트폴리오 탐색기, 프로젝트 상세 사례, 소개, 기술, 경험, 연락처, 메모, 터미널, 테마·설정.
- **일반 페이지 보기**: 같은 콘텐츠를 일반적인 반응형 포트폴리오 페이지로 제공합니다. 브라우저 인쇄에서 PDF로 저장할 수 있습니다.
- **이력서**: 입력된 PDF 링크가 있으면 해당 파일을 엽니다. 없으면 현재 콘텐츠를 Markdown 문서로 다운로드합니다. 이메일 버튼은 사용자의 메일 앱을 엽니다. 메시지를 서버에 전송하지 않습니다.
- **전체 앱**: 컴포넌트 플레이그라운드, 테마 편집기 등 전체 앱.
- **테마 편집기**: 4가지 프리셋, 색·폰트·모서리·그림자·블러·동작·밀도 조정, CSS / JSON / Tailwind 설정 내보내기, JSON 검증 가져오기.
- **터미널**: `help`, `about`, `whoami`, `skills`, `projects`, `experience`, `contact`, `theme`, `date`, `clear`. 개인화한 콘텐츠를 사용하며 실제 시스템 명령은 실행하지 않습니다.

창 이동·크기 조절·최소화·최대화·겹침 순서와 위치 복원을 지원합니다. 모바일에서는 앱 런처와 전체 화면 앱으로 전환되며, **홈** 버튼으로 런처에 돌아옵니다. 모든 앱이 열려 있어도 모바일 키보드 포커스는 활성 앱에 제한됩니다. 320px부터 작은 모바일, 태블릿, 데스크톱을 위한 레이아웃과 짧은 화면·인쇄 스타일이 포함됩니다.

## 키보드와 접근성

- `⌘ / Ctrl + K`: 포트폴리오·앱·프로젝트 검색.
- 검색: `↑ / ↓`, `Enter`, `Escape`.
- 창 제목 표시줄 포커스 + `Alt + 방향키`: 이동.
- 창 오른쪽 아래 크기 조절 핸들 포커스 + `방향키`: 크기 조절.
- 터미널: `Tab` 자동완성, `↑ / ↓` 명령 기록.
- 네이티브 대화상자 포커스 관리, 입력 레이블, 포커스 표시, OS 동작 줄이기, 고대비·투명도 설정을 제공합니다.

전체 WCAG 적합성, Safari / Firefox 실기기 검증, Lighthouse와 Core Web Vitals 점수는 별도 측정이 필요합니다.

## 포함된 파일

- `index.html`: 포트폴리오 템플릿. 독립 실행 가능합니다.
- `design-system.html`: 처음 만든 영문 제품 랜딩 페이지·디자인 시스템 보관본. 현재 한국어 포트폴리오는 `index.html`입니다.
- `README.md`: 사용법.
- `VERIFICATION.md`: 실제 수행한 검증과 한계.

데이터는 브라우저 `localStorage`에 저장됩니다. 다른 브라우저·파일 경로·도메인에서는 초안이 다를 수 있고, 브라우저 데이터를 지우면 없어집니다. 백업에는 HTML 또는 JSON 내보내기를 사용하세요. 개인화 HTML은 공개용 콘텐츠와 테마·설정을 포함하고, 메모와 가상 파일은 포함하지 않습니다.

## 정적 호스팅

별도 빌드 없이 `index.html` 또는 내보낸 HTML을 정적 호스팅에 올릴 수 있습니다. 이 작업에서는 공개 배포하지 않았습니다.

## 한국어 화면과 움직이는 배경

포트폴리오, 편집기, 메뉴, 설정, 검색, 기본 예시 콘텐츠를 한국어로 제공합니다. 기존에 작성한 사용자 소개·연락처·프로젝트·메모는 보존하며, 기본 영문 예시와 정확히 일치하는 문구만 한국어로 바꿉니다.

기존 배경의 4개 물결 층과 2개 윤곽선은 SVG 곡선 자체가 서로 다른 주기로 변하며 자연스럽게 흐릅니다. 시작과 끝 모양을 일치시켜 반복 지점의 끊김을 없앴습니다. 마우스를 움직이면 배경이 최대 가로 10px·세로 7px 범위에서 관성 있게 따라오며, 포인터가 나가면 서서히 중앙으로 돌아옵니다.

모바일·터치 환경에서는 마우스 반응을 사용하지 않고 물결 진폭을 절반으로 줄여 조금 더 느리게 움직입니다. 기기 센서나 권한은 필요하지 않으며, 터치·앱 스크롤을 가로채지 않습니다. **설정 → 움직이는 배경**을 끄면 물결과 마우스 반응이 함께 멈춥니다. **화면 동작**을 끄거나 OS의 동작 줄이기를 사용해도 둘 다 멈춥니다. 일반 페이지 보기·백그라운드 탭·인쇄 중에는 일시정지합니다.

외부 영상·라이브러리는 사용하지 않습니다. 물결 보간은 브라우저의 SVG 애니메이션이 맡고, JavaScript 프레임 갱신은 데스크톱 마우스 반응이 변하는 동안만 실행한 뒤 멈춥니다. 모바일에서는 이 마우스 갱신 루프를 사용하지 않습니다.

모바일에서 앱을 사용하는 동안에는 배경 물결을 잠시 쉬게 해 그리기 작업을 줄입니다. 홈 복귀·마지막 앱 종료·최소화 후에는 멈췄던 흐름에서 이어집니다. 가려진 앱의 내용과 스크롤은 유지하며, 비활성 창의 그리기와 활성 창을 누를 때의 중복 갱신을 줄였습니다. 브라우저에서 측정한 비교 수치와 재현 방법은 `performance/README.md`에 있습니다. 실제 휴대폰·Safari 검증과 배터리 측정은 별도입니다.
