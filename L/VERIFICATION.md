# L 포트폴리오 확인 기록

2026-10-21, 로컬 HTTP 미리보기와 브라우저 뷰포트 기준으로 확인했습니다.

## 원본 비교

- 원본 CSS와 로컬 CSS는 자산 URL만 정규화하면 일치합니다. 원본 레이아웃·반응형 선언을 유지했습니다.
- 1280×720에서 원본과 L의 헤더 1280×72, 첫 화면 1280×720 일치.
- 첫 화면과 프로젝트 카드에서 실제 `three.js r183` canvas 생성 확인.
- SVG 그림 대신 원본의 유리 렌더러를 사용하며, 모델 윤곽·아이덴티티·문구·프로젝트 내용은 L 포트폴리오로 변경했습니다.

## 동작

- 모바일 전체 메뉴 열기, Projects 선택 후 메뉴 닫힘과 해당 위치 이동. 메뉴 잠금 중에도 앵커 이동이 실행되도록 Lenis의 해당 호출에 `force: true`를 적용했습니다.
- 데스크톱 섹션 탐색, Back to Top, 원본의 텍스트 reveal·통계 roller.
- 프로젝트 이미지의 WebGL 변형, 서비스 sticky 구역의 순차 이동: 스크롤에 따라 `--home-service-image-y` 값이 변하는 것과 실제 화면 확인.
- ATLAS 상세: 데스크톱·모바일에서 열기, 모바일 내부 가로 넘침 없음, Escape 닫기와 기존 링크로 포커스 복원.
- 기록 상세 열기·닫기.
- 라이트·다크 테마 전환과 실제 캡처.
- 언어 메뉴의 한국어 링크로 로컬 `ko.html` 이동, 중국어 `zh.html` 렌더링.
- 하단 CREATIVE 윤곽 글자와 유리 L 표시. V2 버튼은 원본처럼 숨겨져 있으므로 V2 전환 실행 검사는 하지 않았습니다.
- 확인한 브라우저 콘솔의 오류·경고 없음. 실제 로딩된 이미지의 깨진 경로 없음.

## 정적 검사와 최상위 연결

- HTML·실행 스크립트·폰트·이미지를 L 폴더에 포함했습니다. 모듈 소스는 일반 스크립트 번들로 빌드되어 열람 시 모듈 다운로드가 필요하지 않습니다.
- `node --check`로 포트폴리오 스크립트·실행 번들·최상위 스크립트 문법 확인, `git diff --cached --check` 통과. HTML의 상대 경로·앵커·중복 ID·외부 실행 의존성과 SVG XML 검사 통과.
- ZIP의 L 파일 49개가 원본 파일과 바이트 단위로 일치하며 M 폴더가 포함되지 않는 것 확인.
- 원본 회사의 추적·분석 스크립트, 서버 라우팅·폼 제외.
- 최상위 목록 6개, L 준비 완료, 상단 바로가기·카드·열기 링크의 `L/index.html` 연결 확인.
- 이전 M 폴더와 M 링크를 L로 변경. 이전 M 즐겨찾기 ID도 L로 마이그레이션합니다.
- 원본의 reduced-motion 분기는 유지했습니다. 운영체제 설정 변경 검사는 하지 않았습니다.
- 브라우저 도구의 프로토콜 제한으로 파일 직접 실행 검사는 하지 않았습니다. HTTP 미리보기와 상대 경로·일반 스크립트 구성을 확인했습니다.
