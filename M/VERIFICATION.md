# M 포트폴리오 확인 기록

2026-10-21, 로컬 정적 미리보기와 브라우저 뷰포트 기준으로 확인했습니다.

## 반응형

| 뷰포트 | 페이지 가로 넘침 | 첫 화면 제목이 조형물 구역 안에 들어오는지 |
| --- | --- | --- |
| 320×740 | 없음 | 정상 |
| 375×812 | 없음 | 정상 |
| 390×844 | 없음 | 정상 |
| 768×1024 | 없음 | 정상 |
| 1024×768 | 없음 | 정상 |
| 1280×720 | 없음 | 정상 |
| 1440×900 | 없음 | 정상 |
| 844×390 가로 화면 | 없음 | 정상. 짧은 화면에서는 첫 구역을 세로로 스크롤 |

`scrollWidth`와 `clientWidth`를 비교했습니다. 실제 모바일 하드웨어·터치 키보드 검사는 별도로 수행하지 않았습니다.

## 동작

- 모바일 메뉴 열기, 메뉴 안 테마 전환, 프로젝트 구역 이동 후 메뉴 닫힘과 스크롤 잠금 해제.
- App / 실험 필터, 전체 세 개 프로젝트 복원, 필터 상태 안내.
- ATLAS / FORM / SIGNAL 상세 열기와 이미지 로딩.
- 상세 화면 Escape 닫기, 이전 프로젝트 버튼으로 포커스 복원, 배경 스크롤 잠금 해제.
- 영어 전환 후 선택한 App 필터 유지, 영어 상세 설명과 역할·유형 표시.
- 라이트 / 다크 테마. 라이트 테마에서는 조형물과 겹치는 제목의 합성을 확인하고 대비를 조정.
- 기록 펼치기.
- 이메일 복사 성공 안내. 검사 전 클립보드 상태로 복원.
- 확인한 브라우저 콘솔 오류·경고 없음.

## 정적 검사

- `node --check M/script.js` 통과.
- HTML의 로컬 이미지·스크립트·스타일·파비콘·폰트 경로, 구역 앵커·메뉴 컨트롤 연결 확인.
- 5개 SVG의 XML 파싱 통과.
- 상세 창을 열었을 때 실제 문서의 ID 중복 없음. HTML template의 사례 제목은 한 번에 하나만 복사합니다.
- 일반 텍스트 색상 대비: 다크 본문 17.44:1, 다크 보조 8.13:1, 라이트 본문 16.70:1, 라이트 보조 5.72:1. 조형물과 합성하는 큰 제목은 별도로 시각 확인했습니다.
- `prefers-reduced-motion` CSS 규칙과 JavaScript 분기를 코드에서 확인했습니다. 운영체제 설정을 바꾸는 검사는 수행하지 않았습니다.
- 외부 CDN·API·모듈 로딩·원본 사이트에 의존하는 실행 경로 없음.

로컬 파일 직접 열기는 브라우저 도구의 프로토콜 제한 때문에 실행 검사하지 않았습니다. 실행 검사는 로컬 HTTP 미리보기로 했으며, 파일 실행에 필요한 상대 경로와 일반 스크립트 구성을 정적으로 확인했습니다.
