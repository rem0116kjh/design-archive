# ORBIT — SPACE PORTFOLIO TEMPLATE

후배들과 공유하고, 각자의 이야기로 바꿔 쓰는 우주 포트폴리오 디자인 템플릿입니다.

**회전하는 지구 · 앞뒤로 도는 프로젝트 카드 · 드래그 · 4단계 스크롤 장면 전환**이 중심입니다. 개인 이름·메일·계정·실제 프로젝트·학교·경력·수상 기록을 넣지 않았습니다. 화면에 보이는 프로젝트와 타임라인은 모두 예시입니다.

## 바로 열기

`index.html`을 브라우저에서 열면 됩니다. 설치·빌드·API 키·프레임워크가 필요하지 않습니다. 폴더 전체를 함께 전달하세요.

로컬 서버를 쓰고 싶다면 이 폴더에서 실행합니다.

```sh
python3 -m http.server 4187 --bind 127.0.0.1
```

브라우저: `http://127.0.0.1:4187` / 종료: `Ctrl+C`

## 처음 바꿀 곳

1. `script.js` 맨 위 `TEMPLATE`: 브랜드, 이메일, GitHub, 지구·궤도 회전 속도
2. `index.html`: 메인 문구, 자기소개, 사용 기술, 프로젝트, 경험
3. `assets/project-*.svg`: 프로젝트 이미지. 직접 찍은 화면으로 교체 가능
4. `style.css` 맨 위 `:root`: 색상, 폰트, 여백
5. 실제 사이트를 배포할 때 메타 설명·OG 이미지·canonical URL 설정

```js
const TEMPLATE = Object.freeze({
  brand: 'ORBIT',
  email: 'hello@example.com',
  github: 'https://github.com/',
  orbitSpeed: 0.19,
  globeSpeed: 0.09
});
```

연락처의 `hello@example.com`은 예약된 예시 주소입니다. GitHub 링크도 서비스 홈페이지로만 연결됩니다. 배포 전 본인의 주소로 바꾸세요. HTML에도 JavaScript 없는 환경을 위한 같은 예시 값이 있으므로 함께 바꿔 주세요.

## 핵심 인터랙션

- **지구 자전:** Vanilla WebGL의 구체 투영에 지표·구름 텍스처와 조명·대기 효과를 적용
- **프로젝트 공전:** HTML 카드가 타원 궤도를 돌며 지구의 앞·뒤를 통과. 궤도 방향에 따라 카드 면이 3D로 기울어지는 원근 적용
- **직접 회전:** 좌우 드래그, 모바일 가로 스와이프, 방향 버튼, 키보드 좌우 화살표
- **스크롤 장면 전환:** 화면을 고정한 채 궤도 탐색 → 지구 약 2배 확대 → 카드가 화면 전체로 펼쳐짐 → 다음 이야기로 진입
- **장면 탐색:** 하단 01–04 버튼으로 원하는 장면 이동. 위로 스크롤하면 같은 경로로 되돌아옴
- **탐색 안정성:** 카드에 마우스나 키보드 포커스를 두면 자동 공전 정지
- **독립 정지:** 메뉴·상세 팝업을 열거나 화면 밖으로 나가거나 탭을 숨기면 프레임 루프 정지
- **모션 접근성:** 시스템 모션 줄이기와 수동 정지 지원. 정지하면 긴 고정 구간이 일반 첫 화면으로 바뀜. 이후 섹션을 읽던 위치는 유지되며, 방향 버튼·드래그로 직접 조작 가능
- **자연스러운 터치:** 가로 조작과 세로 페이지 스크롤을 구분
- **화면별 배치:** 데스크톱의 좌우 구성이 모바일에서는 지구 → 텍스트 순서로 변경

WebGL을 사용할 수 없는 환경에서는 CSS 구체와 움직이는 표면으로 대체합니다. 외부 이미지 요청 없이 `file://`에서도 텍스처가 적용되도록 `assets/earth-textures.js`에 데이터를 포함했습니다.

## 구현과 성능

HTML5 · CSS3 · Vanilla JavaScript만 사용합니다. React·Three.js·애니메이션 라이브러리는 사용하지 않습니다.

구체는 삼각형 두 개와 프래그먼트 셰이더로 그립니다. 하나의 `requestAnimationFrame` 루프가 별·자전·공전을 함께 갱신합니다. 모바일에서는 별 개수와 Canvas 해상도를 줄이고 24fps 갱신 상한을 사용합니다. 데스크톱은 30fps 상한입니다. 이 수치는 구현상의 상한이며, 실측 기기 FPS를 의미하지 않습니다.

스크롤 연출은 CSS `position: sticky`와 현재 페이지 위치를 사용합니다. 휠·세로 터치 이벤트를 가로채거나 스크롤을 잠그지 않습니다. 데스크톱은 520svh, 모바일은 440svh 구간을 사용하며, 각 장면의 이동·확대·투명도는 `assets/scroll-story.js`의 `update()`에서 수정할 수 있습니다. 카드의 펼침 위치는 `assets/universe.js`의 `fanPositions`에 있습니다. JavaScript 또는 모션이 꺼지면 긴 빈 구간이 생기지 않습니다.

프로젝트 필터, 접근 가능한 네이티브 상세 팝업, 이메일 복사, 모바일 메뉴, 키보드 포커스 순환, 화면 밖 모션 중단을 포함합니다. JavaScript 없이도 콘텐츠와 링크를 읽을 수 있습니다.

## 브라우저 검증

2026-10-21, macOS Chrome에서 확인했습니다. 실물 모바일 기기 검증은 포함하지 않습니다.

- 320·375·390·768·1024·1440px: 전체 섹션 가로 넘침 없음, 이미지 정상
- WebGL 자전·공전 진행, 마우스 드래그, 키보드 수동 회전 정상
- 4개 장면의 고정 위치·지구 확대·카드 펼침·역방향 스크롤을 화면 크기별로 확인
- 장면 버튼 이동, 화면 크기 변경, 모션 전환 후 읽던 위치와 프로젝트 직접 링크 확인
- 모바일 터치 이벤트로 카드 위 가로 스와이프와 세로 스크롤을 각각 확인
- 화면 밖 자동 정지, 시스템 모션 줄이기, 설정 저장 정상
- 필터, 네이티브 상세 팝업, Escape, 포커스 복원, 모바일 메뉴 정상
- 파일 직접 열기에서도 WebGL 정상, WebGL 없는 환경의 CSS 대체 경로 확인
- JavaScript 없는 환경에서도 메뉴와 콘텐츠 탐색 가능
- 모바일 Lighthouse: 접근성 100 / SEO 100 / Best Practices 100, 실패 항목 0개
- 이전 개인 식별자와 실제 경력·프로젝트·로컬 사용자 경로가 소스·문서에 남아 있지 않음을 검색 확인
