# REM WORLD — 퍼플·그린 HTML 포트폴리오 템플릿

`index.html`을 더블클릭하면 바로 실행됩니다. HTML · CSS · JavaScript와 폰트·이미지가 이 폴더에 들어 있어 설치, 빌드, 서버, 로그인 없이 사용할 수 있습니다.

파일 하나만 옮기지 말고 이 폴더 전체를 복사하세요. GitHub Pages에서도 같은 파일을 그대로 사용할 수 있습니다.

## 파일 구조

```text
피치월드/
  index.html            소개·프로젝트·연락처
  style.css             색상·레이아웃·반응형
  script.js             메뉴·필터·이메일 복사·서울 시계
  assets/               폰트·배경·일러스트·라이선스
  preview/              화면 예시
  REFERENCE_ANALYSIS.md 참고 사이트 분석
```

## 내 내용으로 수정

1. `index.html`에서 이름·소개·프로젝트 설명과 링크·이메일을 수정합니다.
2. 이메일은 화면의 주소와 `mailto:` 링크를 함께 수정합니다. 복사 버튼은 화면에 표시된 주소를 사용합니다.
3. `style.css` 맨 위 `:root`에서 보라·그린·노랑·분홍 색상을 변경합니다.
4. `assets/`의 일러스트를 바꿀 때 파일 이름이나 HTML의 상대 경로를 맞춥니다.

현재 소개·프로젝트는 김진형(Rem)의 포트폴리오 예시입니다. 다른 사람이 사용할 때 본인의 실제 내용으로 교체하세요. 프로젝트 카드의 폰 화면·터미널·대화창은 설명용 그래픽입니다.

## 제공 기능

대각선 게이트, 데스크톱 hover·키보드 focus 확장, 모바일 설명·버튼 상시 표시, 메뉴와 Escape 닫기, 프로젝트 분류, 이메일 복사, 모션 줄이기, 키보드 탐색을 지원합니다. 파일 직접 실행 시 브라우저가 클립보드를 제한하면 주소를 선택해 직접 복사할 수 있습니다.
