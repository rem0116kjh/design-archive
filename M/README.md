# M — Creative Developer Portfolio

[MAKERVIL](https://www.makervil.com/en)의 타이포그래피·금속 조형물·비대칭 배치·모바일 탐색에서 영감을 받아 만든 개인 포트폴리오 템플릿입니다. 원본 사이트의 회사 콘텐츠·제품 사진·로고·3D 모델은 포함하지 않습니다.

**이 폴더의 `index.html`을 더블클릭하세요.** HTML·CSS·일반 JavaScript로 동작하며 설치·빌드·서버가 필요하지 않습니다. 이미지와 폰트도 이 폴더에 포함되어 있습니다.

## 구성

- 큰 타이포그래피와 금속 M 조형물이 있는 첫 화면.
- 소개 → 세 가지 작업 관점 → 프로젝트 → 작업 방식 → 기록 → 연락처.
- 한국어 / 영어 전환, 라이트 / 다크 테마.
- 프로젝트 분류 필터와 세 개의 사례 상세 창.
- 휴대전화용 전체 화면 메뉴. 링크 선택·닫기·Escape, 키보드 포커스 복원 지원.
- 터치 화면에서는 호버가 없어도 프로젝트 제목·설명·열기 버튼이 보입니다.
- 동작 줄이기 설정 대응. 포인터 효과와 스크롤 진입 효과를 줄입니다.
- 이메일 복사. 브라우저가 복사를 허용하지 않으면 주소를 선택하고 수동 복사를 안내합니다.

언어·테마만 현재 브라우저의 `m-portfolio.language.v1`, `m-portfolio.theme.v1`에 저장합니다. 저장 공간이 제한돼도 현재 탭의 기능은 사용할 수 있습니다. 프로젝트 내용이나 개인 데이터를 서버로 보내지 않습니다.

## 내 포트폴리오로 바꾸기

1. `index.html`에서 M의 이름, 소개, 프로젝트 이미지·제목·역할, 작업 방식, 기록을 바꿉니다.
2. 상세 사례는 HTML 마지막의 `<template id="project-atlas">`, `project-form`, `project-signal`에서 수정합니다. 카드의 `data-project`와 템플릿 ID가 연결됩니다.
3. `hello@example.com`을 본인의 이메일로 **모두** 바꿉니다. 이메일 링크와 복사 버튼은 `.email-link`의 내용을 사용합니다.
4. 영어 문구는 `script.js`의 `english` 객체에서 수정합니다. 한국어 원문은 HTML의 `data-copy` 요소입니다. 언어를 바꿔도 프로젝트 필터와 현재 스크롤 위치는 유지됩니다.
5. 이미지는 `assets/`에 넣고 HTML의 `src`·`alt`·크기를 함께 바꿉니다. 프로젝트 수를 바꾸면 필터 버튼의 개수 표기도 맞춰 주세요.
6. 색은 `style.css`의 `:root`, `:root[data-theme="light"]` 변수로 바꿉니다. 기본 테마는 다크입니다.
7. 공유할 때는 `M` 폴더 전체를 전달하세요. 정적 호스팅에서도 같은 파일을 사용할 수 있습니다.

M이라는 인물, ATLAS·FORM·SIGNAL 프로젝트와 사례 설명은 템플릿용 예시입니다. 실제 수상·경력·사용자 성과를 주장하지 않습니다. 자신의 정보로 바꾼 뒤 사용하세요. 이메일 링크는 메일 앱을 열며 이 페이지에서 메시지를 전송하지 않습니다.

## 반응형과 접근성

큰 화면은 분산된 제목과 2열 비대칭 프로젝트 배치를 사용합니다. 800px 이하에서는 메뉴를 별도 창으로 바꾸고, 540px 이하에서는 프로젝트를 한 열로 보여줍니다. 작은 화면에서 조형물을 중앙에 두고 제목과 설명의 위치를 조정합니다. 가로 화면·확대 글자·긴 문장에서는 높이를 고정하지 않고 내용이 흐르도록 구성했습니다.

주요 버튼은 최소 44px 높이입니다. 바로 가기 링크, 포커스 표시, native dialog, Escape 닫기, 필터 상태 안내, 본문 제목 계층을 제공합니다. 네트워크·빌드·프레임워크 의존성은 없습니다. 구형 브라우저에서는 `dialog`, `color-mix`, 최신 뷰포트 단위 지원이 필요할 수 있습니다.
