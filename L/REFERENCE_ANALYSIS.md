# MAKERVIL → L 적용 기록

후배들을 위해 제작한 디자인 포트폴리오의 L 디자인 참고 자료 및 구현 분석 문서입니다.

참조: [MAKERVIL 영문 홈페이지](https://www.makervil.com/en) — 2026-10-21에 공개 홈페이지와 실행 자산을 확인했습니다.

## 디자인과 반응형

원본 홈페이지 DOM과 318,868바이트의 CSS를 사용했습니다. CSS의 `url(...)`을 동일한 토큰으로 정규화했을 때 원본과 로컬 파일이 일치합니다. 자산 경로 외에 원본의 크기·여백·타이포그래피·반응형 선언을 변경하지 않았습니다. 포트폴리오 상세 창 스타일은 별도 `portfolio.css`에 있습니다.

원본의 560px·767px·959px 등 구간별 규칙, 화면 높이에 대응하는 첫 화면 구성, 데스크톱 분산 제목·비대칭 카드와 모바일 메뉴를 유지했습니다. 텍스트의 길이와 L의 윤곽은 요청에 따라 달라지므로 원본 화면과 모든 픽셀 값이 동일하다고 주장하지 않습니다.

## 3D

원본은 GLB 동영상이 아니라 Three.js r183에서 SVG 윤곽을 실제로 돌출시킨 모델입니다. 같은 렌더러·카메라 맞춤·환경 조명·텍스트 backdrop·포인터 반응·idle 회전을 사용하고 윤곽만 L로 바꾸었습니다.

유리 재질의 주요 값은 원본과 같습니다: transmission 1, roughness 0.02, thickness 0.2, ior 1.5, clearcoat 0.25, reflectivity 1, iridescence 0.22. 원본 extrusion 깊이 비율 0.135와 bevel 0.032도 유지했습니다. WebGL을 쓸 수 없거나 동작 줄이기가 설정된 환경의 분기는 원본 구현을 따릅니다.

로딩 큐브·연락처 심벌도 L로 변경했고 하단 입체 글자는 CREATIVE로 바꾸었습니다. 하단의 포인터 반응·재질은 원본 구현입니다. 원본처럼 기본 화면은 V1이며, 숨겨진 V2 물리 모드 소스도 포함되어 있습니다.

## 스크롤과 인터랙션

원본 `home-intro.js`, `site-cursor.js`, 이미지 변형 shader, glass module, Three.js와 Lenis를 로컬로 포함했습니다. `page-transition.js` 중 홈페이지 연락처 parallax만 추출했습니다. 문장 단위 등장, 숫자 roller, 카드의 WebGL 변형, 서비스 sticky 진행, 뉴스 preview, 연락처 이동과 footer physics를 유지합니다.

원본 서버 라우팅·회사 폼·분석 스크립트는 제외했습니다. 탐색은 포트폴리오 섹션으로 연결되며 프로젝트와 기록은 native dialog에서 열립니다. 상세 창은 배경 스크롤을 멈추고 닫을 때 기존 버튼으로 포커스를 복원합니다.

## 콘텐츠

회사 소개와 실적 대신 개인 소개·세 가지 콘셉트·도구/분야/기록 개수, 프로젝트 ATLAS·FORM·SIGNAL, 조사→디자인/개발→개선 과정과 기록 6개를 넣었습니다. 원본의 서비스 사진은 조형적 디자인 요소로 유지하고 제품 설명은 개인 작업 방식으로 교체했습니다. 다국어 탐색과 테마 전환은 로컬 페이지·브라우저 저장소에서 작동합니다.
