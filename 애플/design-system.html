LUKA UI is an exploration of how the web can feel more intentional. A design system and a working desktop, brought together with care, curiosity, and a little less complexity.

Semantic HTMLModern CSSVanilla JavaScriptDesign tokensLocal-first
01   An interface that does more.

Visual polish matters most when the interactions work. This workspace connects a virtual file explorer, persistent notes, a simulated terminal, window management, and theme editing in a single, self-contained HTML file.

02   Built simply. By intention.

No framework, build step, external fonts, or remote assets. CSS variables connect the interface to one theme model. Pointer events handle window movement and resizing. Each application owns its content while one manager handles focus, placement, and stacking.

03   Made for people, and their preferences.

Native buttons, labeled form controls, visible focus states, keyboard search, modal focus containment, reduced motion, and high-contrast preferences. On smaller screens, apps become focused views with a touch-friendly app switcher.

04   Honest about what’s measured.

Performance depends on your device and browser. Lighthouse, Core Web Vitals, and cross-browser accessibility results are not claimed here. Use the browser’s developer tools to audit this local page. See README.md for implementation scope and verification.

05   The maker & the next chapter.

Made by LUKA as a frontend and interaction design portfolio project. Personal career history, achievements, and contact details have not been supplied. The next chapter can add real project case studies and verified performance results.
